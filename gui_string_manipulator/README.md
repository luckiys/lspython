# GUI String Manipulator

A graphical user interface application for string manipulation and analysis.

## Features

- Interactive GUI with buttons and text entry
- Title-case conversion
- Character counting (specific letters)
- Word counting
- Real-time results display

## Skills Demonstrated

- GUI programming with graphics library
- Event-driven programming (button clicks)
- String methods (title, count, split)
- Object-oriented concepts

## Requirements

- Python 3
- graphics.py (included)
- button.py (included)

## How to Run

```bash
python3 gui_string_app.py
```

## Screenshot

The application displays:
- Text input field
- "Analyze" button to process the string
- Results showing:
  - Title Case version
  - Number of 'r's
  - Number of words
  - Character count
