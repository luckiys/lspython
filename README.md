# Python Programming Portfolio

A collection of Python projects developed during CNIT 155 at Purdue University, demonstrating core programming concepts and problem-solving skills.

## 🚀 Projects

### 1. Inventory Management System
**File:** `inventory_management_system.py`

A product inventory system that manages items, applies discounts, and searches products by price threshold.

**Features:**
- Add and display product information (name, ID, price, quantity)
- Calculate average prices
- Apply percentage-based discounts
- Filter products above a price threshold

**Skills Demonstrated:** Functions, Lists, Loops, Formatted Output, User Input

---

### 2. GPA File Processor
**File:** `gpa_file_processor.py`

Reads student data from a file, processes GPAs, assigns letter grades, and writes results to an output file.

**Features:**
- Read and parse CSV-formatted data
- Find maximum scores
- Apply grade curves
- Convert GPA to letter grades (A+, A, B, C, D, F)
- Write formatted results to output file

**Skills Demonstrated:** File I/O, Exception Handling, String Parsing, Data Processing

---

### 3. Triangle Validator & Calculator
**File:** `triangle_validator.py`

Validates if three sides can form a valid triangle and calculates the area using Heron's formula.

**Features:**
- Triangle inequality validation
- Area calculation using Heron's formula
- Input validation with continue/exit options
- Mathematical computations

**Skills Demonstrated:** Functions with Return Values, Math Library, Input Validation, While Loops

---

### 4. GUI String Manipulator
**Folder:** `gui_string_manipulator/`

A graphical user interface application for string manipulation and analysis.

**Features:**
- Interactive GUI with buttons and text entry
- Title-case conversion
- Character counting (specific letters)
- Word counting
- Event-driven programming

**Skills Demonstrated:** GUI Programming, Graphics Library, Event Handling, String Methods

---
