# Python Programming Portfolio

A collection of Python projects developed during CNIT 155 at Purdue University, demonstrating core programming concepts and problem-solving skills.

---

## 📁 Projects

| Project | Description | Key Skills |
|---------|-------------|------------|
| [Inventory Management System](./inventory_management_system) | Product inventory with discounts & search | Functions, Lists, Loops |
| [GPA File Processor](./gpa_file_processor) | Read/write student data, assign grades | File I/O, Exception Handling |
| [Triangle Validator](./triangle_validator) | Validate triangles, calculate area | Math Library, Validation |
| [GUI String Manipulator](./gui_string_manipulator) | GUI app for string operations | Graphics, Event Handling |

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/luckiys/lspython.git
cd lspython

# Run any project
python3 inventory_management_system/inventory_management_system.py
python3 gpa_file_processor/gpa_file_processor.py
python3 triangle_validator/triangle_validator.py
python3 gui_string_manipulator/gui_string_app.py
```
