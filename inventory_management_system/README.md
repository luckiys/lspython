# Inventory Management System

A product inventory system that manages items, applies discounts, and searches products by price threshold.

## Features

- Add and display product information (name, ID, price, quantity)
- Calculate average prices
- Apply percentage-based discounts
- Filter products above a price threshold

## Skills Demonstrated

- Functions with parameters and return values
- Lists for data storage
- Loops (for and while)
- Formatted output with f-strings
- User input handling

## How to Run

```bash
python3 inventory_management_system.py
```
